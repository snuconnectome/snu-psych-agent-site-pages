    연습 과제¶

    에이전트에게 일을 맡기고 결과를 확인하는 감각을 익히는 과제 3개입니다. 모든 자료는 연습용으로 만든 가짜 자료이고, 개인정보가 없습니다.

    과제 하는 일 Flash 비용(실측) Pro 비용(실측)
    과제 1: 반응시간 자료 정리 참가자별 CSV 합치기 → 제외 기준 → 조건별 평균·표준오차 약 3~4원, 15초 약 15~18원, 20~30초
    과제 2: 상호작용 그래프 2×2 설계 평균·표준오차 표와 오차막대 그래프 약 3~4원, 12초 약 15~17원, 20~30초
    과제 3: 실험 시행 목록 생성기 조건 균형·연속 제한이 있는 Stroop 시행 목록 약 6~9원, 30~40초 약 20~62원, 40초~4분

    비용은 2026-10-10에 같은 과제를 OpenCode로 2번씩 풀어 잰 값입니다. 평일 낮 일부 시간대에는 DeepSeek 단가가 더 높을 수 있습니다(확인 중). 월 한도(약 5만원)로 이런 과제를 수천 번 풀 수 있지만, 실제 연구 작업은 자료와 맥락이 커서 훨씬 많이 듭니다.

    진행 방법¶

    1. 과제 파일(zip)을 내려받아 풉니다. 아래는 과제 1의 예입니다. 풀면 과제 폴더 하나와 점검 스크립트(*_check.py) 하나가 나옵니다.

      mkdir -p ~/agent-tasks && cd ~/agent-tasks
cp /mnt/c/Users/<Windows 사용자 이름>/Downloads/task1_rt_cleaning.zip .
unzip task1_rt_cleaning.zip

      mkdir -p ~/agent-tasks && cd ~/agent-tasks
cp ~/Downloads/task1_rt_cleaning.zip . && unzip task1_rt_cleaning.zip

      mkdir $HOME\agent-tasks -Force; cd $HOME\agent-tasks
Expand-Archive $HOME\Downloads\task1_rt_cleaning.zip -DestinationPath .

    2. 과제 폴더로 들어가 opencode를 실행하고, 이렇게 시작해 보세요. 

      cd task1_rt_cleaning
opencode
      OpenCode 화면이 뜨면 아래 문장을 입력합니다. 
      이 폴더의 instruction.md 를 읽고 그대로 수행해 줘. 스크립트는 실제로 실행해서 결과 파일까지 만들어 줘.

    3. 에이전트가 끝나면, 결과를 직접 열어 보고 말이 되는지 확인합니다. 에이전트가 「완료했다」고 해도 틀릴 수 있습니다.
    4. 점검합니다. OpenCode를 끝내고(Ctrl+C. 한 번에 안 꺼지면 한 번 더), 한 단계 위 폴더로 나가서 점검 스크립트를 실행합니다. 
      cd ..
python3 task1_rt_cleaning_check.py task1_rt_cleaning
      Windows PowerShell에서는 python3 대신 python을 씁니다. PASS가 나오면 통과입니다. FAIL이면 다시 과제 폴더로 들어가 opencode를 실행하고 무엇이 틀렸는지 에이전트에게 물어보세요.

    점검 스크립트에 대해

    점검 스크립트 안에는 정답 값이 들어 있습니다. 먼저 열어 보지 말고, 에이전트가 낸 결과를 스스로 검증해 본 뒤에 쓰세요. 점수는 본인만 보고, 성적이나 평가에 쓰지 않습니다.

    잘 쓰는 요령 (과제를 하며 연습할 것)¶

    • 결과 파일 이름과 형식을 정확히 말하기: 「results/summary.csv에 condition,mean_rt,se 열로」처럼.
    • 과정을 스크립트로 남기게 하기: 나중에 다시 돌리거나 남에게 보여 줄 수 있어야 연구에 쓸 수 있습니다.
    • 다른 방법으로 대조하기: 「같은 평균을 다른 방법으로 한 번 더 계산해서 맞는지 확인해 줘」.
    • 두 번 실패하면 Pro로: /models에서 바꿉니다.
