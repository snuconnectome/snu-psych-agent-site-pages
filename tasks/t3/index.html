    과제 3: 실험 시행 목록 생성기¶

    과제 파일 내려받기 (task3_stroop_trials.zip)

    PsychoPy·jsPsych에 넣을 Stroop 시행 목록을 만드는 Python 스크립트를 작성합니다. 96시행, 일치·불일치 각 48, 색과 단어 조합 균형, 같은 조건 4번 이상 연속 금지, 같은 단어 연속 금지, 시드로 재현 가능해야 합니다.

    • 배우는 것: 여러 제약을 동시에 만족하는 코드를 맡기고, 제약이 정말 지켜졌는지 확인하기
    • 결과 파일: make_trials.py, trials.csv(trial,word,ink,condition)
    • 점검: python3 task3_stroop_trials_check.py task3_stroop_trials

    확인해 볼 것

    세 과제 중 가장 어렵습니다. 실측에서 Pro가 한 번은 4분 넘게 걸렸습니다. 에이전트에게 「제약을 하나씩 검사하는 코드도 같이 만들어 줘」라고 하면 스스로 확인하게 할 수 있습니다.
