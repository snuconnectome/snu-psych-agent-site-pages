    다른 학과에게¶

    이 프로그램은 다른 학과가 그대로 가져다 쓸 수 있게 만들고 있습니다. 시범(2027-1학기)이 끝나면 아래 자료를 공개할 계획입니다(공개 시점과 라이선스는 결정 대기). 학생 데이터, 키, 개인 결과는 공개하지 않습니다.

    자료 내용
    이 사이트 안내·설치·연습 과제 페이지. 바꿀 곳은 저장소 README에 정리되어 있습니다
    운영 자료 키 발급·회수 절차, 월간 설문 문항, 사용자 모임 진행안
    비용 모델 인원·한도·모델 비율을 넣으면 연간 비용이 나오는 계산표와 시범 실측 결과

    도입 판단표 (우리 시범 기준, 2026-10 계획)¶

    항목 우리 시범 메모
    인원·기간 20명, 4개월(2027-03~06) 결과를 보고 확대
    학생 사용료 1인 월 약 5만원 상한(키 한도 월 $32) 전원이 한도를 다 쓰면 20명 4개월 약 360만원
    담당자 조교 1명. 사이트 유지 월 약 3.5시간(추정) + 키 관리·질문 응대 조교 도구 지원(Claude Code) 월 $200 별도, 4개월 약 120만원
    시범 총액 최대 약 480만원(환율에 따라 약 520만원까지) 실사용이 적으면 줄어든다
    필요한 계정 OpenRouter 조직 계정(학생별 키 발급), 사이트를 올릴 곳(GitHub Pages 등) 키 관리 도구와 절차는 시범 뒤 공개 예정
    아직 정하지 않은 것 선발 기준, 문의 채널, 공개 시점·라이선스 결과 공개 시 함께 정한다

    시작에 필요한 최소 구성¶

    1. OpenRouter 조직 계정 1개, 학생별 키(월 한도·만료일·허용 모델 지정)
    2. 이 사이트 복제와 학과 이름·한도 수정(README의 「바꿀 곳」)
    3. 담당자 1명과 질문 받을 채널 1개
    4. 월 1회 짧은 설문

    선행 사례 (조사일 2026-10-10, 기관 공식 페이지 기준)¶

    기관 프로그램 대상·규모 제공 비용 부담 우리와 다른 점
    KAIST 전산학부 생성형 AI 에이전트 기반 연구지원 석·박사 연구자, 기수당 20명 Claude Code·Codex, 교육, 정기 세미나 동문 기부 구조가 가장 비슷하다. 평가 방법은 공개하지 않았다
    Harvard FAS OpenAI for Community Developers, AI Sandbox FAS 구성원 1인 월 $10 OpenAI API 크레딧, 다중 모델 샌드박스 대학 개인 월 크레딧이지만 교육·모임이 붙어 있지 않다
    Duke OIT AI Gateway for Developers 학생·교수·직원 다중 모델 API 키, 개인 예산·사용량 대시보드, 사용자 그룹 클라우드 모델은 비용 회수 게이트웨이 장애 때 키를 모두 재발급해야 했다
    Edinburgh ELM 전 학생·교직원 다중 모델 게이트웨이, API 키, 예제·교육 대학 대학 전체 서비스다
    LSE Claude for Education 파일럿 교원·학생 Claude, AI Fluency 과정 대학·Anthropic 협약 익명 집계 사용 데이터로 교육 효과를 연구한다
    Oxford 전 학생 ChatGPT Edu 전 학생·교직원 ChatGPT Edu, AI Ambassadors 대학 직원 750명 1년 파일럿 뒤 전체로 넓혔다
    전남대 생성형 AI 8종 제공 구성원 약 3만 명 통합 플랫폼(크레딧제) 대학 학내 언론에 따르면 코딩 작업 한 건에 하루 크레딧의 17%가 들어 불만이 나왔다
    서울대 본부 ChatGPT Edu(Codex 포함) 재학·재직 구성원 ChatGPT, Codex 대학 우리 참여자도 함께 쓴다. 이 프로그램은 그 위에 더하는 것이다

    찾지 못한 것 - 국내외 심리학·사회과학 학과가 직접 운영하는 같은 종류의 프로그램은 찾지 못했다(찾아본 곳: ac.kr·.edu·.ac.uk 검색, 계명대 심리학과 게시판, LSE 심리·행동과학과). - 월간 설문·모임으로 사용 경험을 재고 그 결과를 공개한 사례도 찾지 못했다.

    이 프로그램이 다른 점 - 비전산 학과가 소수 인원에게 터미널형 코딩 에이전트와 개인 예산을 준다. - 오픈소스 에이전트와 다중 모델 라우터로 비용을 낮춘다. - 측정 방법과 결과를 다른 학과가 다시 쓸 수 있게 공개한다.
