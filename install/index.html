    시작 전에¶

    설치는 세 단계입니다. OpenCode 설치 → 학과에서 받은 키 등록 → 첫 명령 실행. 보통 20~30분 걸립니다.

    준비물¶

    • 노트북(Windows 10 이상, macOS, Linux)
    • 학과에서 메일로 받은 개인 키(sk-or-로 시작하는 긴 문자열). 다른 사람에게 보내거나 GitHub 같은 공개된 곳에 올리지 마세요.
    • 터미널. macOS는 기본 「터미널」, Windows는 WSL(권장) 또는 PowerShell을 씁니다.
    • 순서: OS별 OpenCode 설치 → Python 확인 → 공통 설정 파일 → 키 등록 → 첫 명령

    Python 확인¶

    연습 과제의 점검 스크립트는 Python 3로 돌아갑니다. 터미널에서 확인하세요.

    python3 --version
sudo apt update && sudo apt install -y python3 python3-pandas python3-matplotlib unzip
    두 번째 줄은 Ubuntu(WSL 포함)용입니다. 과제에 필요한 pandas·matplotlib와 압축 풀기 도구를 한 번에 설치합니다.

    python3 --version
    「명령어 라인 개발자 도구를 설치하겠습니까」 창이 뜨면 「설치」를 누르고 끝난 뒤 다시 확인합니다. 그래프 과제에는 matplotlib가 필요합니다: python3 -m pip install --user pandas matplotlib

    python.org에서 설치하고, 설치 첫 화면의 「Add python.exe to PATH」를 꼭 체크합니다. Microsoft Store 창이 뜨는 python3 대신 python 으로 실행합니다. 

    python --version
python -m pip install pandas matplotlib

    공통 설정 파일¶

    OS별 설치를 마친 뒤, 아래 명령을 그대로 복사해 붙여 넣으면 설정 파일이 만들어집니다. 편집기로 직접 고치면 따옴표가 바뀌어 파일이 깨질 수 있으니 명령으로 만드세요. 이 파일은 기본 모델을 DeepSeek Flash로 정하고, Pro로 바꿔 쓸 수 있게 합니다.

    mkdir -p ~/.config/opencode
cat > ~/.config/opencode/opencode.json <<'EOF'
{
  "$schema": "https://opencode.ai/config.json",
  "model": "openrouter/deepseek/deepseek-v4.1-flash",
  "small_model": "openrouter/deepseek/deepseek-v4.1-flash",
  "provider": {
    "openrouter": {
      "models": {
        "deepseek/deepseek-v4.1-flash": {
          "options": {"provider": {"order": ["deepseek"], "allow_fallbacks": false}}
        },
        "deepseek/deepseek-v4-pro-0813": {
          "options": {"provider": {"order": ["deepseek"], "allow_fallbacks": false}}
        }
      }
    }
  }
}
EOF
python3 -m json.tool ~/.config/opencode/opencode.json > /dev/null && echo "설정 파일 OK"

    New-Item -ItemType Directory -Force "$HOME\.config\opencode" | Out-Null
@'
{
  "$schema": "https://opencode.ai/config.json",
  "model": "openrouter/deepseek/deepseek-v4.1-flash",
  "small_model": "openrouter/deepseek/deepseek-v4.1-flash",
  "provider": {
    "openrouter": {
      "models": {
        "deepseek/deepseek-v4.1-flash": {
          "options": {"provider": {"order": ["deepseek"], "allow_fallbacks": false}}
        },
        "deepseek/deepseek-v4-pro-0813": {
          "options": {"provider": {"order": ["deepseek"], "allow_fallbacks": false}}
        }
      }
    }
  }
}
'@ | Set-Content -Encoding utf8 "$HOME\.config\opencode\opencode.json"
Get-Content "$HOME\.config\opencode\opencode.json" | ConvertFrom-Json | Out-Null; "설정 파일 OK"

    마지막 줄에서 「설정 파일 OK」가 나오면 됩니다. 오류가 나면 명령을 처음부터 다시 붙여 넣습니다.

    키 등록 (모든 OS 같음)¶

    1. 작업할 폴더로 이동한 뒤 opencode를 실행합니다.
    2. OpenCode 안에서 /connect를 입력하고 openrouter라고 쳐서 OpenRouter를 고릅니다. 목록에 안 보이면 opencode --version으로 버전을 확인하고 조교에게 알려 주세요. 이 안내는 OpenCode 1.18.35와 공식 문서(2026-10-08 수정판)로 확인했습니다.
    3. 학과에서 받은 키를 붙여 넣습니다. 키는 내 컴퓨터의 ~/.local/share/opencode/auth.json에 저장됩니다.

    Flash와 Pro 바꾸기¶

    • 기본은 Flash입니다. 대부분의 자료 정리·분석 작업은 Flash로 충분하고 비용이 약 5분의 1입니다.
    • 어려운 작업(여러 파일을 고치는 일, Flash가 두 번 실패한 일)은 /models에서 deepseek/deepseek-v4-pro-0813을 고릅니다.
    • 다른 모델은 학과 키로는 쓸 수 없습니다. 고르면 「0 endpoints … guardrail」 같은 오류가 납니다.

    한도¶

    • 한 달 약 5만원어치를 쓸 수 있고, 매월 1일 오전 9시(한국 시간)에 다시 채워집니다.
    • 한도에 닿으면 그달에는 호출이 멈춥니다. 추가 요금은 청구되지 않습니다.
    • 연습 과제 1개는 Flash로 약 3~9원, Pro로 약 15~62원 들었습니다(2026-10-10 실측, 과제 안내).
